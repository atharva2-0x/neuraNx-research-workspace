NeuraNx · FDE solutionProblem statement

A fluent answer can still
be the wrong answer

An analyst needs to interrogate a 50-page fund report spanning historical performance, quarterly tables, portfolio allocations, and forecasts.

Evidence is fragmented

Numbers, footnotes, charts, and assumptions live on different pages. A summary alone hides their provenance.

The source conflicts with itself

Repeated quarterly tables disagree. Forecasts and actuals need separate labels. Currency glyphs are unresolved.

Accuracy must be inspectable

Numeric answers need deterministic calculations, exact page references, and explicit disclosure of missing or conflicting evidence.

Check the brief
against the actual artifact

50 pages · 346 observations

49 extracted tables. Every observation retains its raw token and provenance. The report generates eight warnings and five informational notes.

36 tests · 12 scenarios

Local checks cover extraction, arithmetic, citations, ambiguity, uploads, document isolation, source rendering, review state, and provider fallback.

Two useful corrections

The sample quarterly inputs compound to 16.74%. The chart’s highest tick, 360, is not its axis maximum; the 390.3 forecast fits within the plotted range.

Default retrieval is BM25 keyword search. Provider embeddings, LLM composition, and PostgreSQL/pgvector are optional paths; live provider calls have not been exercised.

OCI · Live demo server

Running on an Always Free VM.Standard.E2.1.Micro instance in Mumbai, with 1 GB RAM and a 46.6 GB boot volume. FastAPI runs as a managed service. Vercel connects through an approved Cloudflare HTTPS demo tunnel. The tunnel address can change if its service restarts; use a permanent hostname or named tunnel for production.

PDF uploads use private browser workspaces, with original files and extracted evidence stored on OCI. Hosted limits: 4 MB, 200 pages, and 10 reports per workspace. Findings export as a formatted, printable HTML report.

Customer deployment requires authentication, per-document authorization, durable jobs, retention controls, monitoring, and a labeled evaluation set. Always Free eligibility depends on the tenancy’s home region, remaining allowance, and available host capacity.
